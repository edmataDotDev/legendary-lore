# legendary-lore-rag

Corpus of lore for legendary, mythical and other notable Pokémon (one Markdown file per Pokémon,
grouped by generation under `gen-N/`), intended as the knowledge base for a RAG pipeline that will
later be packaged and consumed by the [pokédex](https://github.com/edmataDotDev) agent project.

Each file carries YAML frontmatter with `pokemon`, `generation`, `source`, `license` and `retrieved`.
